# Woody Sort Game - Color Sort Puzzle 🪵🎨

A high-performance, relaxing, and aesthetic **Woody Sort Game** (Color Sort Puzzle) built with **Astro 5**, TypeScript, and modern Web Audio API.

## ✨ Features

- 🪵 **Authentic Rustic Wooden Aesthetics**: Hand-crafted wooden tubes, smooth shadows, and realistic 3D ball spheres.
- 🔊 **Zero-Latency Procedural Web Audio**: Acoustic wooden knocks, ball pops, drop bounces, victory arpeggios, and optional zen forest breeze ambience.
- 💡 **Built-In Smart AI BFS Solver**: Instant hint calculator that highlights the optimal next move.
- 🧪 **Game Boosters**: Full Undo history, +1 Auxiliary Wooden Tube, Smart Hints, and Instant Level Restart.
- 🏆 **50+ Progressive Levels & Secret Chambers**: Tutorial to Master levels plus hidden mystery challenges (e.g. *Emerald Relic*, *Amber Sunstone*, *Redwood Vault*).
- 📱 **Mobile & Desktop Responsive**: Touch, drag, and click controls with keyboard shortcuts (`1-9` for tubes, `U` for undo, `H` for hint, `R` for restart).
- 🔍 **Full SEO Optimization**: Structured data schemas (`WebApplication`, `VideoGame`, `HowTo`, `FAQPage`), sitemap, and dedicated guide pages.

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Ishadwgn/Woody-Sort.git

# Navigate to project directory
cd Woody-Sort

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:4321/` in your browser.

### Build for Production

```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack

- **Framework**: [Astro 5](https://astro.build/)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Modern Design System)
- **Audio**: Web Audio API (Synthesized Procedural Sound Effects)
- **Effects**: Canvas Confetti
